## 4. 注意点・学んだこと

### docs 修正の作業手順

1. **必ず `main` ブランチで直接編集**してコミット（miyata/task-1 等でコミットしない）
2. 全ブランチに `git checkout <branch> && git checkout main -- docs/` で同期
3. `git push --no-verify origin main task-1 task-2 task-3 task-4 task-5` で一括 push
4. `miyata/task-1` に戻って `git rebase task-1` で最新の docs を反映

### やってはいけないこと

- ユーザーの作業ファイル（Vue, TS, package.json 等）を誤ってコミットしない
- `miyata/task-1` で docs をコミットしない（main でやる）
- ユーザーに「全体を進めて」と言われていないのに先のステップまで実装しない

### cherry-pick の注意

- `git cherry-pick --no-verify` は無効なオプション（`--no-verify` は cherry-pick にない）
- miyata/task-1 の stash から main に変更を持っていく場合は、main で直接編集する方が確実
